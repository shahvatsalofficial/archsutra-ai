# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive. Critique ideas, not people.
- No harassment, discrimination, or personal attacks.
- Assume good faith; explain reasoning with evidence.
- Do not share others' private information.

Report concerns privately through GitHub (repository Security tab or by contacting the maintainer, @shahvatsalofficial). Maintainers may remove content or restrict participation that violates these rules.
