# Report template

1. Executive summary (goals, top 3 risks, business impact)
2. Scope, method, coverage, blind spots
3. Current state (diagrams, components, data flows)
4. Findings (sorted by severity)
5. Scorecard (strong / adequate / weak / critical / not assessed, each with basis)
6. Roadmap (phases, dependencies, rollback)
7. Recommended ADRs
8. Unverified assumptions and open questions
