    Cheat sheet

    One page: every command, flag, exit code, output file, label and install path.

    Version 0.1.5 · Source: docs/guides/cheat-sheet.md

    Print it, pin it, or keep this tab open.

    The five commands you will use most#

    npx archsutra-ai audit .                       # findings + scorecard, printed
npx archsutra-ai audit . --output arch-report  # full report set: HTML + Markdown + JSON + SARIF
npx archsutra-ai audit . --fail-on high        # CI gate (exit 1 on high or critical)
npx archsutra-ai drift . --baseline baseline/findings.json --fail-on high   # only NEW findings fail
npx archsutra-ai install --host claude --target .   # add skills and agents to your IDE

    All commands#

    CommandWhat it doesWrites files?
    audit [path]Evidence-linked findings and scorecardwith --output
    map [path]Modules, imports, cycles, diagramswith --output
    review [path]Audit evidence as a review starterwith --output
    design [path]Design starter from the module map; decisions stay unknownwith --output
    threat-model [path]STRIDE starter from security findings; the rest stays unknownwith --output
    modernize [path]One slice per finding; target architecture stays unknownwith --output
    cost [path]States that cost is not assessedwith --output
    drift / compareDiff two findings.json files, or a project against --baselineno
    verify [path]Check skills, agents, links, diagrams, findings.jsonno
    export [path]Write every report as Markdown and HTMLyes
    html <file.md>Render a Markdown report to a self-contained HTML pageyes (next to the file)
    install / uninstallAdd or remove skills and agents (--host, --target)yes
    doctor [path]Check Node, hosts, install driftno
    hostsList adapters and support levelsno
    mcpMCP server on stdio (tools: audit, map, drift)no

    None of them calls a model or the network.

    Flags#

    FlagMeaning
    --jsonMachine-readable output
    --format <md|html>Stdout format for audit and map
    --output <dir>Write files into a folder inside the project
    --baseline <file>findings.json to diff against (drift, compare)
    --fail-on <sev>Exit 1 at or above critical, high, medium or low
    --host <id>claude, cursor, codex, copilot, gemini
    --target <dir>Project to install into
    --dry-runShow changes, write nothing
    --forceOverwrite modified files (backups kept)
    --verboseExtra detail

    Exit codes#

    CodeMeaning
    0Success, or nothing at or above --fail-on
    1Finding at or above --fail-on (for drift: added), or install conflict, or failed doctor
    2Usage error
    4verify failed
    5Internal error

    FileForOpen it with

    audit-report.html / .mdThe findingsbrowser / pull request
    current-state.html / .mdStack, maps, diagrams, cyclesbrowser / pull request
    findings.jsonScripts and drift baselinesyour tooling
    findings.sarifGitHub code scanningupload action

    Claim labels#

    LabelMeaning
    observedSeen in a file; cites path:line
    inferredDerived from observed facts; says from what
    proposedA recommendation, not a fact
    unknownCannot be decided from the evidence; says what would settle it

    Ratings#

    strong (no findings from the rules we have) · adequate (medium findings) · weak (high) · critical · not assessed (needs evidence a static scan cannot see).

    Severity guide#

    SeverityRough meaning
    criticalExploitable now with major impact (exposed secret, private key)
    highSerious weakness with a plausible exploit or outage
    mediumMeaningful risk or debt
    lowHygiene
    infoObservation

    Where skills land per IDE#

    HostSkillsAgents
    Claude Code.claude/skills/.claude/agents/
    Cursor.cursor/skills/.cursor/agents/
    OpenAI Codex.agents/skills/none (managed block in AGENTS.md)
    GitHub Copilot.github/skills/.github/agents/*.agent.md
    Gemini CLI.gemini/skills/none

    Install one host per project: several hosts also read .agents/skills and .claude/skills.

    The five skills#

    SkillAsk it when
    architecture-audit"Review this codebase"
    architecture-design"How should we build this?"
    architecture-modernization"How do we get off the legacy system safely?"
    threat-modeling"What could go wrong with this feature?"
    architecture-verification"Check this report before I send it"

    Limits to remember#

    5 000 files · 512 KiB per file · 120 MiB total · 15 s traversal · lines over 2 000 characters skipped · symlinks never followed · writes only inside the project.

    Suppress a finding#

    .archsutra/suppress.json:

    { "suppress": [ { "rule": "AS-SEC-006", "path": "src/dev.ts", "reason": "Dev only", "expires": "2027-03-31" } ] }

    A row needs a reason; expired rows are ignored.
