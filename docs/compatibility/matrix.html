Compatibility matrix

Version 0.1.1 · Source: docs/compatibility/matrix.md

Levels: native (host loads ArchSutra directly, verified in a live session), adapter (files written to the vendor-documented layout, checked against vendor docs, not yet smoke-tested live), manual (copy-paste fallback), experimental (layout unconfirmed), unsupported.

OpenAI Codexadapter.agents/skills/<name>/SKILL.md + AGENTS.md blocknone2026-11-01file generationlive discovery
GitHub Copilotadapter.github/skills/<name>/SKILL.md.github/agents/<name>.agent.md (description, tools)2026-11-01file generation, frontmatter keyslive behavior
Gemini CLIadapter.gemini/skills/<name>/SKILL.mdnone2026-11-01file generationlive discovery; the docs site announces Antigravity CLI as successor, re-verify

Overlap warning: Cursor and Copilot also read .claude/skills and .agents/skills; Gemini CLI reads .agents/skills; Cursor reads .codex/skills. Install one host per project to avoid the same skill appearing twice.
