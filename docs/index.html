Frequently asked questions

What is ArchSutra AI?

An open-source software architecture agent: portable Agent Skills plus a deterministic offline CLI that help AI coding assistants audit, design, threat-model and modernize software with file-and-line evidence.

Do I need an API key?

No. The CLI is offline. Inside a supported AI IDE the skills use that IDE's own model, so you need access to the IDE, not an ArchSutra key.

Does it send my code anywhere?

The CLI sends nothing anywhere and has no telemetry. When you use the skills, your AI IDE's model provider processes your prompts and code under its own terms.

Which AI tools does it support?

Adapters exist for Claude Code, Cursor, OpenAI Codex and GitHub Copilot (adapter level) and Gemini CLI (experimental). Live smoke tests are pending and stated openly.

Does it certify compliance or security?

No. Reports are review aids. Absence of findings is not proof of absence of vulnerabilities, and nothing here is legal advice or a compliance attestation.
