    How it works

    Two parts, two jobs. The CLI measures. Your IDE's own model reasons. The skills keep the model honest.

    1

    Measure

    The offline CLI walks your files read-only, maps modules and imports, applies 19 rules and redacts secrets. Same input, same output.

    2

    Reason

    In your IDE, Prime and eleven specialists open each cited line, drop what they cannot reproduce, and judge impact and trade-offs.

    3

    Deliver

    One report in HTML for people, Markdown for pull requests, JSON and SARIF for tools, with every claim labeled.

    Proof, with the caveats

    We audited 52 public repositories and labeled 98 findings by hand. The first version was only 50% right. We published that, fixed it, and measured again on repositories we had never tuned on.

    Read the whiskers. Small samples, one labeler, recall not measured. About half of valid findings need no action. Live behavior inside each AI IDE, an independent security review, trademark clearance and a lawyer's review are not done, and we say so.

    Frequently asked questions

    What is ArchSutra AI?

    An open-source software architecture agent: portable Agent Skills plus a deterministic offline CLI that help AI coding assistants audit, design, threat-model and modernize software with file-and-line evidence.

    Do I need an API key?

    No. The CLI is offline. Inside a supported AI IDE the skills use that IDE's own model, so you need access to the IDE, not an ArchSutra key.

    Does it send my code anywhere?

    The CLI sends nothing anywhere and has no telemetry. When you use the skills, your AI IDE's model provider processes your prompts and code under its own terms.

    How accurate is it?

    On repositories not used for tuning, 69% then 95% of sampled findings were genuine instances of the rule, and about half were worth acting on. Samples are small and one labeler did the labeling; every label is published.

    Which AI tools does it support?

    Adapters exist for Claude Code, Cursor, OpenAI Codex, GitHub Copilot and Gemini CLI. All are adapter level: files follow each vendor's documented layout, and live smoke tests are still pending.

    Does it certify compliance or security?

    No. Reports are review aids. Absence of findings is not proof of absence of vulnerabilities, and nothing here is legal advice or a compliance attestation.
