CLI reference

Every command, option, exit code and output file of the archsutra CLI.

Version 0.1.0 · Source: docs/handbook/06-cli-reference.md

archsutra <command> [path] [options]

path defaults to the current directory.

Commands#

CommandWrites files?Needs model?Description
init [path]nonoDetect the project and AI hosts; print an install plan per detected host
doctor [path]nonoCheck Node, hosts, install drift, duplicate AGENTS.md blocks
map [path]nonoPrint current-state report: stack, modules, dependencies, cycles, blind spots, Mermaid diagrams
audit [path]nonoRun the rules; print the report or JSON
verify [path]nonoValidate skills, agents, links, diagrams, findings.json
export [path]yes (in --output)noWrite the documentation set
installyesnoInstall skills/agents for --host into --target
uninstallyesnoRemove files this tool installed
hostsnonoList adapters and support levels
versionnonoPrint version
design, review, threat-model, modernize, compare, cost, driftnoyesExit 3 and point to the skill. No API call is made

Options#

OptionApplies toMeaning
--jsonmostMachine-readable output
--dry-runexport, install, uninstallShow what would change; write nothing
--output <dir>exportOutput directory inside the project (default docs/architecture); paths that escape the project are rejected
--host <id>install, uninstallclaude, cursor, codex, copilot, gemini
--target <dir>install, uninstallProject to modify (default .)
--forceinstallOverwrite conflicting files after backing them up
--fail-on <sev>auditExit 1 if any finding is at or above critical, high, medium or low
--verboseallExtra detail; stack trace on internal error
--version, --helpall

Exit codes#

CodeNameWhen
0oksuccess
1findings--fail-on threshold met, install blocked by conflict, or doctor found a problem
2usageunknown command, missing --host, invalid --fail-on, --output escaping the project
3needs modela model-dependent command was invoked in the CLI
4verify failedat least one verify check failed
5errorunexpected internal error

Output files from export#

FileFormatContents
README.mdMarkdownIndex of the set
current-state.mdMarkdown + MermaidStack, C4-style context and module diagrams, module table, cycles, blind spots
audit-report.mdMarkdownSummary, scorecard, findings, scope and blind spots
findings.jsonJSON, schema 1.0.0Findings, scorecard, coverage, blind spots, failed checks
findings.sarifSARIF 2.1.0One result per evidence location
architecture-register.jsonJSONArtifact list with SHA-256 hashes and timestamp

Real examples: examples/brownfield-monolith/sample-output/.

Examples#

archsutra audit . --fail-on high              # CI gate
archsutra audit . --json | jq '.findings[] | {id, severity, title}'
archsutra export . --output docs/architecture
archsutra install --host copilot --target . --dry-run
archsutra install --host codex --target .
archsutra uninstall --host codex --target .
archsutra verify .

Environment#

None required. The CLI reads no environment variables and sends no data anywhere.
