Architecture

C4 views, runtime flows, trust boundaries, quality attributes and the decisions behind ArchSutra AI.

7. Architectural decisions#

ADRDecision
ADR-0001Deterministic CLI for evidence plus IDE-native skills for reasoning; no server, no API key

Additional decisions captured in the RFC: single canonical source with generated host layouts; honest capability labels; zero runtime dependencies; module-level (not file-level) dependency graph for stability.

8. Documentation site#

The HTML site is generated by scripts/build-docs.mjs from this handbook's Markdown. It is static, has no framework, supports light and dark themes, keyboard navigation, a skip link, visible focus, reduced-motion, print styles, and loads one optional script (Mermaid, pinned) from a CDN. Markdown remains the source of truth.

9. Evolution#

Planned additions are intentionally outside the keyless path: optional local model runtime and optional bring-your-own-key server. They must not change default behavior. See Compatibility and roadmap.
