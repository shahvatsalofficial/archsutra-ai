Glossary#

Agent SkillA folder with a SKILL.md (name, description, instructions) that an AI assistant loads on demand. Specification: agentskills.io
Agent role / sub-agentA scoped persona with its own contract (for example Sentinel for security) that the host can delegate to
ArchSutra PrimeThe orchestrating agent: scopes, delegates, synthesizes
AdapterCode that renders canonical skills/agents into a host's folder layout
EvidenceA reference to where a claim comes from: path:line or a named document
observed / inferred / proposed / unknownClaim labels. Observed = seen in source. Inferred = reasoned from observations. Proposed = recommended future design. Unknown = not determinable
FindingA reported issue with ID, severity, confidence, evidence, fix
SeverityImpact if the finding is real: critical, high, medium, low, info
ConfidenceHow sure the rule is that it is real: high, medium, low

FAQ#

What is ArchSutra AI? An open-source software architecture agent: Agent Skills plus a deterministic CLI that help AI coding assistants audit, design, threat-model and modernize software, with evidence for every claim.

Do I need an API key? No. The CLI is offline. Inside a supported AI IDE the skills use that IDE's own model, so you need access to the IDE, not an ArchSutra key.

Does it send my code anywhere? The CLI sends nothing anywhere. When you use the skills, your IDE's model provider processes your prompts and code under its own terms.

Which AI tools work? Adapters exist for Claude Code, Cursor, OpenAI Codex, GitHub Copilot (adapter level) and Gemini CLI (experimental). Live verification is pending; see compatibility.

How is it different from asking an AI to review my code? It enforces a method: measured evidence first (module graph, rule findings with file and line), claim labels, mandatory caveats, a verification step, and a defined specialist team. It also gives repeatable results in CI.

How is it different from SonarQube, Semgrep or CodeQL? Those are mature, deep analyzers. ArchSutra is a lightweight architecture-level reviewer plus an AI workflow; it complements them rather than replacing them. It emits SARIF so results can sit beside theirs.

Can it replace an architect or a pen test? No. It accelerates review and documents evidence. Humans own decisions.

Is it safe to run on my repo? Yes for the analysis commands: read-only, offline, no code execution, symlinks skipped, secrets redacted. export, install and uninstall write inside the project only, and --dry-run shows changes first.

Why did it flag something that is fine? Rules are heuristics. Each finding lists caveats. Treat it as a lead to verify.

Why is Reliability / Performance / Cost "not assessed"? A static scan cannot see runtime load, incidents or billing. The rating is honest rather than invented.

Can I use it commercially? Yes under Apache-2.0 (keep the license and NOTICE). The project name has not been trademark-cleared; see legal.

Does it certify compliance (GDPR, SOC 2, ...)? No. Never. It produces review aids only.

How do I add a rule or a language? See the contributor guide.

Where are the test results? Testing and proof and docs/proof/.

Is it on npm? Not yet. Use npx github:shahvatsalofficial/archsutra-ai ....

Who made it? Created by Vatsal Shah, with Claude assisting in implementation. Contributors are credited in git history.
