    Good first issues (ready to file)

    A starter backlog of well-scoped tasks for new contributors, each with an acceptance test.

    Version 0.1.5 · Source: docs/community/good-first-issues.md

    Each item is small, has a clear test, and matches a known limitation. Open them as GitHub issues with the labels good first issue and help wanted.

    #TitleAreaAcceptance test
    1Smoke test report: Claude CodecompatibilityRow added to docs/compatibility/smoke-tests/README.md with version and evidence
    2Smoke test report: Cursorcompatibilitysame
    3Smoke test report: OpenAI Codexcompatibilitysame
    4Smoke test report: GitHub Copilotcompatibilitysame
    5Smoke test report: Gemini CLI or Antigravity CLIcompatibilitysame; note the successor tool status
    6Go import graph (import "..." of module-internal packages)analyzerFixture with a Go cycle is reported by AS-ARC-001
    7Java/Kotlin import graphanalyzerFixture with a package cycle is reported
    8C# using graphanalyzerFixture with a namespace cycle is reported
    9Rust mod/use crate:: graphanalyzerFixture with a module cycle is reported
    10Suppression file (.archsutraignore or inline archsutra-ignore: AS-SEC-005 reason)featureTest: suppressed finding disappears; suppression without a reason is rejected
    11Baseline mode: report only findings that are new since a saved findings.jsonfeatureTest with two runs
    12Port-aware AS-IAC-001 for Kubernetes Service and IngressruleFixture: public 443 not flagged, public 22 flagged
    13Rule: missing HEALTHCHECK in Dockerfile (info)ruleTrue-positive and false-positive tests
    14Rule: GitHub Actions pull_request_target with checkout of PR headruleFixture and test
    15Rule: GitHub Actions using unpinned uses: referencesruleFixture and test
    16Label 20 more real findings and open a PR adding them to docs/proof/realworld/evaluationnode scripts/realworld.mjs report reproduces numbers
    17Add 5 more repositories to a new holdout batch and label the sampleevaluationNew labels-<batch>.json and summary

    20Add an --format sarif option to auditfeatureaudit --format sarif equals export SARIF output
