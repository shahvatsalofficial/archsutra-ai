Architecture overview

Version 0.1.0 · Source: docs/architecture/overview.md

ArchSutra has two cooperating halves:

  1. Skills and agents (skills/, agents/): canonical Markdown that an AI IDE loads. Reasoning runs on the IDE's own model.
  2. Deterministic CLI (src/): produces reproducible evidence without any model.

Module responsibilities#

ModuleResponsibility
src/fsutil.tsfile walk with limits (5000 files, 512 KB each, 15 s), ignore lists, symlink skipping, path containment
src/redact.tssecret detection and masking; used for every excerpt
src/map.tsecosystems, frameworks, datastores, infra, module graph, Tarjan cycle detection
src/audit.tsrules to findings with evidence; scorecard with not assessed where evidence is absent
src/report.tsMarkdown, Mermaid, findings JSON (v1.0.0), SARIF 2.1.0, artifact register
src/verify.tsstructural validation of skills, agents, links, Mermaid, findings
src/adapters.tshost specs, install plan with conflict detection, hash manifest, uninstall, doctor
src/cli.tsargument parsing, exit codes, command dispatch
