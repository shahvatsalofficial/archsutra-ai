# AGENTS.md - working on ArchSutra AI

- Language: TypeScript (strict, ESM, Node 20+). Source in `src/`, compiled to `dist/` (gitignored).
- Commands: `npm ci`, `npm run build`, `npm test` (builds, then runs `node --test`), `npm run verify`.
- Canonical content lives in `skills/` and `agents/`. Host layouts are generated by `src/adapters.ts`; never hand-copy skills into host folders.
- Tests build fixtures at runtime in the OS temp dir. Do not commit fake secrets: GitHub push protection may block the push.
- Rules: keep the CLI deterministic and offline. No network calls, no model calls, no telemetry. Redact secrets before any output.
- Never claim a feature works unless a test covers it. Never claim compliance or certification.
- Add or change an audit rule: edit `src/audit.ts`, add a seeded case plus a false-positive test in `test/archsutra.test.mjs`.
