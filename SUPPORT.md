# Support

ArchSutra AI is community-supported open source. There is no service-level agreement.

| Need | Where |
|---|---|
| Question or idea | [GitHub Discussions](https://github.com/shahvatsalofficial/archsutra-ai/discussions) |
| Bug in the CLI, a rule, or an adapter | [Issues](https://github.com/shahvatsalofficial/archsutra-ai/issues/new?template=bug_report.md) |
| A rule produced a false positive or missed something | [False-positive report](https://github.com/shahvatsalofficial/archsutra-ai/issues/new?template=false_positive.md) |
| Report whether the skills load in your AI IDE | [Smoke test report](https://github.com/shahvatsalofficial/archsutra-ai/issues/new?template=smoke_test.md) |
| Security vulnerability | Private advisory: see [SECURITY.md](SECURITY.md). Do not open a public issue |
| Documentation | [Handbook](docs/handbook/README.md) |

Include: the command, the output (redact secrets), your OS, Node version and ArchSutra version (`archsutra --version`).

Target response times (best effort): security reports acknowledged within 7 days; other issues triaged within 14 days.
